# Barbershop-Project
Sharp Cuts booking page

A single-page booking system for a barber shop, built with plain HTML and Supabase.

Customers pick a service, date, and time, and book a chair.
The database blocks double bookings.
The owner logs in to see all bookings.
Setup
Create the bookings table and security rules in Supabase.
Open index.html and set SUPABASE_URL and SUPABASE_KEY (publishable or anon key only).
Deploy with Vercel or open the file in a browser.
